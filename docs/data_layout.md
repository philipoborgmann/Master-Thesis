# Data layout

This document is the canonical reference for the local data layout used by
the pipeline. All paths are repository-relative. None of these files are
committed to git — they must be created locally.

## Required vs. generated

| Path | Required? | Producer |
|------|-----------|----------|
| `Data/Raw/Price/<horizon>/<TICKER>USDT_<suffix>.parquet` | required | manual download / `Crypto _data.py` |
| `Data/Raw/Price/CoinMarketCap/*.parquet` | required | manual (CoinMarketCap export) |
| `Data/Raw/Sentiment/<subreddit>/submission.csv` | required | manual (Pushshift / pmaw / Reddit API) |
| `Data/Raw/Sentiment/st-data-full.{parquet,xlsx}` | required | manual |
| `subreddit_ticker_mapping.xlsx` | required, **tracked in git** | manual |
| `feature_sets.xlsx` | required, **tracked in git** | manual / `configs/feature_sets.yaml` |
| `Data/Raw/Price/validation/*.csv` | generated | `validate-price` |
| `Data/Processed/Sentiment/sentiment_combined.csv` | generated | `load-sentiment` |
| `Data/Transformed/Sentiment_Scored_*.csv` | generated | `score-sentiment --model {vader,finbert,cryptobert}` |
| `Data/Features/price_features_<horizon>.parquet` | generated | `create-price-features` |
| `Data/Features/sentiment_features_<horizon>.parquet` | generated | `create-sentiment-features` |
| `Data/Features/stationarity_*.{parquet,xlsx}` | generated | `stationarity` |
| `Data/Final/features_<horizon>.parquet` | generated | `merge-features` |
| `Data/Final/merge_report.csv` | generated | `merge-features` |
| `Outputs/Signals/<horizon>/<set_id>.parquet` | generated | `run-models` |
| `Outputs/diagnostics/sample_report_<horizon>.md` | generated | `diagnostics` |

## Naming conventions

| File | Pattern |
|------|---------|
| Raw OHLCV          | `Data/Raw/Price/{horizon}/{TICKER}USDT_{suffix}.parquet` |
| Price features     | `Data/Features/price_features_{horizon}.parquet`         |
| Sentiment features | `Data/Features/sentiment_features_{horizon}.parquet`     |
| Final features     | `Data/Final/features_{horizon}.parquet`                  |
| Signal output      | `Outputs/Signals/{horizon}/{set_id}.parquet`             |
| Smoke output       | `Outputs/diagnostics/smoke/...`                          |

`{horizon}` is one of `15min`, `1h`, `4h`, `6h`, `1d`; `{suffix}` is the
filename suffix from `configs/horizons.yaml` (`15m`, `1h`, `4h`, `6h`, `1d`).
`{TICKER}` is uppercase, e.g. `BTC`, `ETH`.

## Horizons currently covered downstream

- Raw price data: 15 min, 1 h, 4 h, 6 h, 1 d
- Price features: 1 h, 6 h, 1 d
- Sentiment features: 15 min, 1 h, 6 h, 1 d
- Final merged features: 1 h, 6 h, 1 d
- Models: 1 h, 6 h, 1 d

> **Note:** Raw 4 h data exists but is **not** part of the downstream
> pipeline. Do not silently extend the pipeline to 4 h.
